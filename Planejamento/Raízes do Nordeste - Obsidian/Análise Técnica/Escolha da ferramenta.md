
* **Candidato mais forte: Python (com FastAPI)**
	* Motivos:
		* Integração direta com documentação Swagger
		* Familiaridade do desenvolvedor (considerando tempo para criação do sistema e maior atenção a detalhes)
		* Leitura de código simples
		* Várias bibliotecas
		* Sistema facilmente escalável
		* Documentação e guias diversos para consultar (Youtube, documentações oficiais, etc.)
	* Desvantagens:
		* Velocidade mais lenta que linguagens compiladas (como C++ ou Java)
		* Segurança mais fraca pelo sistema de tipagem dinâmica (maior risco de vulnerabilidades de segurança, como sobrecarga de buffer e injections)
			* Reforçar essas questões
		* Consome mais memória que linguagens compiladas (complexo para aplicações com recursos limitados)
* Java
	* Motivos:
		* Frameworks robustos (Spring Boot, APache CFX e Restlet) para projetos em larga escala
		* Apoio da comunidade forte
		* Confiável, independente e com documentação extensa
	* Desvantagens
		* Performance menor que C++ (devido à JVM e gerenciamento de memória automático), além de garbage collection, problemas de cache e sincronização entre threads
		* Linguagem complexa e altamente tipada (quando comparada com Python ou C++)
		* Falta de domínio atual do desenvolvedor (muito tempo do projeto seria dedicado à aprender o uso da linguagem em um contexto diferente do tratado em aulas)
